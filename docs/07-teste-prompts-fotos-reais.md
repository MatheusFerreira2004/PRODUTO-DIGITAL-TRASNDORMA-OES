# Teste dos prompts em fotos reais

O centro do produto é "aplique na sua casa". Os prompts só foram usados em casas geradas por IA. Antes do lançamento, testar com fotos reais.

## Fotos necessárias
De 3 a 5 fachadas reais, com permissão do dono, sem número, placa de carro ou pessoas.

| # | Material | Situação | Fonte | Permissão |
|---|---|---|---|---|
| 1 | Madeira / siding | | | ☐ |
| 2 | Tijolo | | | ☐ |
| 3 | Reboco | | | ☐ |
| 4 | Opcional: foto de celular comum, com luz ruim | | | ☐ |
| 5 | Opcional: casa de dois andares | | | ☐ |

## O que testar em cada foto
1. Prompt principal com nível 1, nível 2 e nível 3, em sequência.
2. Um prompt de parte única (porta).
3. Um prompt de comparação de paletas.

## Registro
| Foto | Prompt | Estrutura mantida? | Mudou só o pedido? | Parece real? | Correção usada | Nota (1-5) |
|---|---|---|---|---|---|---|
| | | | | | | |

## Critério para lançar
- Os prompts funcionam nos três materiais sem correção em pelo menos parte dos testes.
- Cada problema recorrente tem um prompt de correção no pacote.
- A melhor foto real vira a demonstração do capítulo *Your home first*.
