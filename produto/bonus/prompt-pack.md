# Bonus 1 · Prompt pack

The book gives you the master prompt and the three levels. This pack goes further: starters for 12 house styles, prompts for each part of the facade, gardens by climate and fixes for when the AI gets it wrong.

**How to use it:** always edit step by step. Level 1 from your photo, Level 2 from Level 1, Level 3 from Level 2. Paste the master prompt, then replace [CHANGES] with lines from this pack.

## Master prompt (same as in *Your home first*)
```
Edit this photo of my house. Keep the house exactly the same: same camera angle
and framing, same roof shape, same number and position of windows and doors,
same porch, steps, walls, trees and neighbouring buildings. Do not add, remove
or move any structural element.

Change only:
[CHANGES]

Keep as is: [KEEP]

Realistic photo, soft natural daylight, outdoor lights off, no people, no text,
no logos, no house numbers.
```

## 5. Fixes
| Problem | Prompt |
|---|---|
| Window or door moved | "Restore the windows and door exactly as in the original photo. Change nothing else." |
| Steps changed | "Make the steps the same number as in the original photo." |
| Roof shape changed | "Restore the roof shape exactly as in the original photo. Keep the new colour." |
| Lights on in daylight | "Turn the outdoor lights off." |
| Stray object or mark | "Remove the [object] next to the [place]. Change nothing else." |
| Painted, cartoon look | "Photorealistic, natural colours, real materials, real daylight." |
| Colour too bright | "Make the [wall / door] colour more muted and natural, as real exterior paint looks in daylight." |
| Too much changed | Go back to the previous image and ask for fewer changes at once. |
