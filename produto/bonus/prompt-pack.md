# Bonus 1 · Prompt pack

Copy, paste, fill in the [brackets]. Always edit step by step: Level 1 from your photo, Level 2 from Level 1, Level 3 from Level 2.

## Master prompt
```
Edit this photo of my house. Keep the house exactly the same: same camera angle
and framing, same roof shape, same number and position of windows and doors,
same porch, steps, walls, trees and neighbouring buildings. Do not add, remove
or move any structural element.

Change only:
[CHANGES]

Keep as is: [KEEP]

Realistic photo, soft natural daylight, outdoor lights off, no people, no text,
no logos, no house numbers.
```

## Level 1: Weekend
```
- Remove weeds, overgrowth and clutter from the yard and walls.
- Lawn mowed and edged; clean, simple garden beds along the house with mulch
  and a few low shrubs.
- Path, steps and porch swept clean.
- Front door painted [COLOUR].
- Two potted plants by the door.
```

## Level 2: One month
```
- Walls repainted [WALL COLOUR]; trim, fascia and window frames repainted
  [TRIM COLOUR], smooth and fresh.
- Shutters (if any) painted [ACCENT COLOUR].
- Broken railings, fence boards or gutters repaired so they look complete.
- New simple mailbox and door hardware in [BLACK / BRONZE / BRASS].
```

## Level 3: Full
```
- New roof in [COLOUR / MATERIAL], same roof shape.
- New [concrete / brick / paved] path and steps, same position and number of
  steps.
- New outdoor wall lights beside the door, switched off.
```

## Single-part prompts

**Door only**
```
Change only the front door: painted [COLOUR], with a [BLACK / BRASS] handle.
Keep everything else exactly the same.
```

**Garden only**
```
Change only the front garden: [foundation bed with low evergreen shrubs and dark
mulch / gravel garden with grasses and succulents / cottage garden with low
flowering shrubs]. Keep the house and everything else exactly the same.
```

**Colour test**
```
Change only the paint colours: walls [HEX or name], trim [HEX or name], door
[HEX or name]. Keep materials, textures and everything else exactly the same.
```

**Brick house: trim only**
```
Keep the brick exactly as it is, unpainted. Change only the window trim, fascia,
gutters and garage door to [COLOUR] and the front door to [COLOUR].
```

## Fix prompts
| Problem | Prompt |
|---|---|
| Window or door moved | "Restore the windows and door exactly as in the original photo. Change nothing else." |
| Steps changed | "Make the steps the same number as in the original photo." |
| Lights on in daylight | "Turn the outdoor lights off." |
| Stray object or mark | "Remove the [object] next to the [place]. Change nothing else." |
| Painted look | "Photorealistic, natural colours, real materials." |
| Too much changed | Go back to the previous image and ask for fewer changes. |
