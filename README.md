# Ruin to Home: The Curb Appeal Lookbook

*Nome provisório.* Produto digital em inglês, vendido por US$ 18 para EUA, Canadá e Austrália.

**Promessa:** *See your home transformed, and know what to do first.*

## Status
Definição do produto em andamento. Nada foi validado com o público ainda.

## Estrutura do repositório
| Pasta / arquivo | Conteúdo |
|---|---|
| `docs/01-definicao-produto.md` | Para quem é, o que é, o que tem dentro, o que não promete |
| `docs/02-plano-de-paginas.md` | Plano página a página (estimativa) |
| `docs/03-producao-de-imagens.md` | Ferramenta, regras, estilo, nomes de arquivo, revisão |
| `docs/04-validacao.md` | Como testar a ideia com os vídeos antes de produzir tudo |
| `docs/05-decisoes-e-pendencias.md` | O que já foi decidido e o que está aberto |
| `casas/` | Uma pasta por casa de exemplo, com prompts e receita |
| `imagens/` | Imagens geradas, com o nome padrão |

## Como trabalhamos
- O texto e os prompts são atualizados aqui.
- As imagens são geradas fora (GPT Image ou Nano Banana) e salvas em `imagens/`.
- O repositório é público: não salve chaves de API nem dados pessoais.
